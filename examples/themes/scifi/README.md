# Sci-Fi theme art

The widget tour's `scifi` theme (`examples/themes/themes.cpp`) is drawn with
art from Kenney's **UI Pack: Sci-fi**, version 2.0, created 19-08-2024:
<https://kenney.nl/assets/ui-pack-sci-fi>.

Licence: Creative Commons Zero (CC0),
<http://creativecommons.org/publicdomain/zero/1.0/>, as the pack's
`License.txt` states: free to use in personal, educational and commercial
projects. Created and distributed by Kenney (www.kenney.nl).

Only the files the theme uses are here, unchanged. The colour folders' files
carry their colour as a prefix; the font's name lost its space.
