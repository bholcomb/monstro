# RPG theme art

The widget tour's `rpg` theme (`examples/themes/themes.cpp`) is drawn with art
from Kenney's **UI pack: RPG extension** (UI Pack, RPG Expansion), files dated
20-04-2014: <https://kenney.nl/assets/ui-pack-rpg-expansion>.

Licence: Creative Commons Zero (CC0),
<http://creativecommons.org/publicdomain/zero/1.0/>, as the pack's
`license.txt` states: usable in personal and commercial projects. By Kenney
Vleugels (www.kenney.nl).

Only the files the theme uses are here. The theme's text uses the examples'
DejaVu Sans; the pack has no font.

- `barBack_horizontal.png`: `PNG/barBack_horizontalLeft.png`, `PNG/barBack_horizontalMid.png`, `PNG/barBack_horizontalRight.png`, joined left to right (pixels copied as they are) so one nine-patch spans them
